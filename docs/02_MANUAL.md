# 02 · The NiaBook operating manual (00–17)

The numbered manual, **charter first**. Almost every book here is a **navigation document** that
points to the real canonical file — we do not keep two copies of anything. The only book written
from scratch is **03 · Product Bible** (mined from the implementation). Launcher:
[`../START_HERE.md`](../START_HERE.md).

> Provenance: a numbered manual skeleton was supplied from a separate empty workspace (it
> described a generic finance app and assumed no code existed). We took its **structure only** and
> grounded every book in this repository. The generic content was discarded, not merged.
